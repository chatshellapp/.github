# ChatShell

A desktop AI agent with built-in web search, file editing, and shell tools.

Plan a trip, compare purchases, prepare a shopping list, or organize your files. Connect a cloud AI provider or local model, and choose when to approve tool actions.

**[Download ChatShell](https://github.com/chatshellapp/chatshell-desktop/releases/latest)** · [Documentation](https://chatshell.app/docs)

Available for macOS, Windows, and Linux. ChatShell is open source under Apache 2.0 and is in active development.

## Explore the Code

Start with **[chatshell-desktop](https://github.com/chatshellapp/chatshell-desktop)** for the app, screenshots, and contribution instructions.

[chatshell-agent](https://github.com/chatshellapp/chatshell-agent) contains the shared Rust agent core used by ChatShell.
